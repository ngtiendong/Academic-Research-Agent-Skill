# Source Grounding Reference

## Rule

No source should be used as evidence until it has been inspected.

Prefer tool-assisted inspection when possible: download the paper, convert the PDF to Markdown, extract figures and tables, then build a source analysis matrix before drafting literature claims.

## Source Labels

- `inspected`: enough source material was reviewed to support claims.
- `downloaded`: PDF was retrieved locally.
- `converted`: PDF was converted into Markdown or structured notes.
- `visuals-extracted`: figures, tables, or captions were extracted for review.
- `abstract-only`: only abstract or metadata was reviewed.
- `pending`: identified but not reviewed.
- `unavailable`: could not be accessed.

## Extraction Checklist

- Citation metadata.
- Problem.
- Method.
- Dataset.
- Metric.
- Main result.
- Figures and tables relevant to the claim.
- Limitation.
- Relevance to current project.
- Claims that can be reused.
- Claims that must not be reused.

## Claim Discipline

Separate:

- What the source says.
- What the agent infers.
- What the researcher hypothesizes.
