# Source Grounding Reference

## Rule

No source should be used as evidence until it has been inspected.

## Source Labels

- `inspected`: enough source material was reviewed to support claims.
- `abstract-only`: only abstract or metadata was reviewed.
- `pending`: identified but not reviewed.
- `unavailable`: could not be accessed.

## Extraction Checklist

- Citation metadata.
- Problem.
- Method.
- Dataset.
- Metric.
- Main result.
- Limitation.
- Relevance to current project.
- Claims that can be reused.
- Claims that must not be reused.

## Claim Discipline

Separate:

- What the source says.
- What the agent infers.
- What the researcher hypothesizes.
