# Contributing

Contributions are welcome if they improve research quality, reproducibility, or usability.

Useful contributions:

- New command prompts.
- Better gate checklists.
- Example research runs with redacted artifacts.
- Language configuration improvements.
- Diagrams and onboarding documentation.
- Adapters for specific agentic coding tools.
- Case studies showing human-agent collaboration.

Please avoid:

- Prompts that encourage fabricated citations.
- Claims of full autonomy without reproducible evidence.
- Domain-specific private data.
- Large generated papers without source traces.
- Messaging that implies the researcher is not involved.
