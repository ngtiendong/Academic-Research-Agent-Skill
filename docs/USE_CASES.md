# Use Cases

## Master Student

Goal: learn how to turn a broad topic into a focused thesis.

Useful commands:

```text
/paper-scope
/lit-ground
/reviewer-sim
```

Expected value:

- clearer research question,
- better understanding of prior work,
- earlier feedback on weak novelty.

## PhD Student

Goal: manage research complexity across papers, experiments, and revisions.

Useful commands:

```text
/pdf-ingest
/math-formalize
/astar-novelty
/reality-gate
/risk-plan
/code-exec-plan
/paper-review-fix
```

Expected value:

- traceable literature grounding,
- stronger contribution framing,
- better experiment planning,
- more systematic response to criticism.

## Research Engineer

Goal: turn a reality-cleared idea into a reproducible pilot.

Useful commands:

```text
/reality-gate
/code-exec-plan
/agent-brief
/phase-exec
/remote-exec
```

Expected value:

- explicit interfaces,
- baseline and metric clarity,
- clear separation between smoke tests and claim-eligible feasibility pilots,
- pilot-first execution after reality clearance,
- structured result artifacts.

## Advisor or Lab Lead

Goal: make AI-assisted research auditable.

Useful artifacts:

- source analysis matrix,
- novelty gate report,
- Reality Gate certificate table,
- risk plan,
- claim verification report,
- changelog.

Expected value:

- fewer hidden assumptions,
- easier supervision,
- clearer human approval points.
