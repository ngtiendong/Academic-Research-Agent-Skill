# Launch Checklist

Use this before making the repository public.

## Must Have

- README with a one-sentence value proposition.
- `SKILL.md` at repo root.
- Quick start that works with a fresh clone.
- Architecture diagram.
- Workflow diagram.
- English prompts.
- Language configuration.
- Example topic brief.
- License.
- Contributing guide.
- Redacted example output.
- Clear statement that the workflow is human-guided, not fully autonomous.

## Strongly Recommended

- 3-5 minute demo video or GIF.
- One complete case study with artifacts:
  - input topic,
  - scope,
  - literature matrix,
  - novelty gate,
  - risk plan,
  - code plan,
  - reviewer simulation.
- Screenshots of the generated artifacts.
- Clear comparison table versus AutoResearchClaw, Agent Laboratory, GPT Researcher, STORM, and PaperQA.
- GitHub topics:
  - `multi-agent`
  - `research-assistant`
  - `literature-review`
  - `llm-agents`
  - `phd`
  - `academic-writing`
  - `prompt-engineering`

## Avoid

- Claiming full autonomy if the repo is a workflow template.
- Publishing private thesis notes or unpublished paper details.
- Showing fake output as if it came from a completed run.
- Overpromising citation verification without artifacts.

## Launch Positioning

Recommended tagline:

> A human-guided research agent for Master and PhD students in CS, AI, math, engineering, and related technical fields.

Recommended first GitHub description:

> Human-guided Research Agent Skill for Master/PhD students in CS, AI, math, and engineering: literature grounding, novelty gates, math formalization, experiment planning, reviewer simulation, and claim verification.
