# Visual Guide

The repo uses two types of visuals:

- Mermaid diagrams for GitHub-native rendering.
- Image-generation prompts for hero images and richer diagrams.

## Mermaid Diagrams

| File | Purpose |
|---|---|
| `docs/visuals/human_agent_collaboration.mmd` | Shows the human-agent-artifact collaboration loop. |
| `docs/visuals/research_lifecycle.mmd` | Shows the end-to-end research lifecycle. |
| `docs/visuals/artifact_pipeline.mmd` | Shows artifact progression. |
| `docs/visuals/learning_loop.mmd` | Shows how students learn through agent collaboration. |

## Recommended README Visual Order

1. Human-agent collaboration loop.
2. Research lifecycle.
3. Artifact pipeline.

## Style Direction for Generated Images

Use images that communicate research collaboration, not "robot writes paper alone." The human should be visually central or equal. The agent system should look like a structured support layer around evidence, papers, code, and review artifacts.
