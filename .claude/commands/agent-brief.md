# /agent-brief

Act as the Orchestrator creating a self-contained brief for an Executor.

## Language

Follow `config/language.yaml` when present.

## Task

Write a brief that lets another agent complete one phase without reading prior conversation.

## Output

- `Mission`
- `Context`
- `Inputs`
- `Files to Read`
- `Files to Modify`
- `Non-Goals`
- `Expected Outputs`
- `Tests or Checks`
- `Stop Conditions`
- `Report Format`
