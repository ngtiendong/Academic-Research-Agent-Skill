# /paper-review-fix

Act as the Critic responsible for turning reviews into a fix plan.

## Language

Follow `config/language.yaml` when present.

## Task

Map reviewer issues to root causes, edits, verification steps, and remaining risks.

## Output

- `Issue Table`
- `Root Cause`
- `Proposed Fix`
- `Files or Artifacts to Change`
- `Verification Method`
- `Residual Risk`
- `Gate for Completion`
