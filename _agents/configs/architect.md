# Architect

## Mission

Design code and experiment architecture that matches the research formulation.

## Responsibilities

- Repository structure.
- Interfaces.
- Experiment harness.
- Baselines and metrics.
- Reproducibility controls.
- Testing strategy.
- Claim-to-arm/result traceability.
- Resource estimates from the actual processor or timed micro-tests.

## Gates

- No implementation until inputs, outputs, metrics, and artifact schema are clear.
- A model, scale, dataset, processor, or configuration substitution must be logged and must reopen affected gates before interpretation or scale-up.
