# Source Ingestion Rule

Sources must be inspected before they are used as evidence.

## Minimum Extraction

- Bibliographic metadata.
- Main claim.
- Method.
- Dataset.
- Metric.
- Key result.
- Limitation.
- Relevance to the current project.

## Labels

- `inspected`: full text or enough source material reviewed.
- `abstract-only`: only abstract or metadata reviewed.
- `unavailable`: source could not be accessed.
- `pending`: source identified but not reviewed.
