# Claim Verification Rule

Every factual claim in a draft must be traceable.

For every retained headline claim, maintain:

`research question -> contribution -> formal claim -> closest competitor and residual delta -> falsifying test/proof obligation or experiment/result ID -> evidence artifact -> paper location -> residual risk`

## Claim Types

- Literature claim: must cite an inspected source.
- Experiment claim: must link to a result artifact.
- Method claim: must link to formalization or implementation.
- Interpretation: must be labeled as interpretation.
- Hypothesis: must be labeled as hypothesis.

Use only `hypothesis`, `supported`, `partially-supported`, `contradicted`, `unverified`, or `dropped` as claim states.

## Blockers

- Fabricated citation.
- Unverified numerical result.
- Claim stronger than evidence.
- Missing baseline for comparative claim.
- Missing falsifier/proof obligation or evidence artifact for a retained headline claim; for assertive empirical claims, missing result ID or paper location.
